# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory introduced the Linux cloud environment using KillerCoda.

## Objectives

- Explore Ubuntu Linux
- Create a new user
- Learn basic Linux commands
- Organize files
- Upload files to GitHub

## Activities Performed

- Started Ubuntu Playground
- Created a Linux user
- Collected system information
- Created folders and markdown files
- Uploaded everything to GitHub

## Linux Commands Used

- pwd
- whoami
- hostname
- uname
- lscpu
- free
- df
- mkdir
- nano
- cat

## Skills Learned

- Linux terminal basics
- File management
- Markdown
- GitHub repository organization
