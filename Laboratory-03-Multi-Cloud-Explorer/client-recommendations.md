# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform

AWS

### Recommendation

I recommend AWS for the startup because it provides scalable services that can support a new mobile application while allowing the company to expand as its user base grows. The startup can begin with appropriately sized cloud resources and increase capacity as demand increases. AWS also provides several managed and serverless services that can reduce the amount of infrastructure the startup needs to manage.

### Possible Services

- AWS Lambda
- Amazon S3
- Amazon RDS
- Amazon EC2

## Client B – University

### Recommended Platform

Microsoft Azure

### Recommendation

I recommend Microsoft Azure because the university already uses several Microsoft technologies. Azure provides strong integration with Microsoft's ecosystem, making it easier to migrate existing Windows-based workloads and connect cloud services with existing identity and productivity systems. This can reduce compatibility and integration challenges during the migration.

### Possible Services

- Azure Virtual Machines
- Azure SQL Database
- Microsoft Entra ID
- Azure Virtual Network

## Client C – AI Research Company

### Recommended Platform

Google Cloud Platform

### Recommendation

I recommend Google Cloud because the company focuses heavily on artificial intelligence and machine learning workloads. Google Cloud provides services and infrastructure designed for AI, machine learning, data processing, and scalable computing. Its support for GPUs, machine learning tools, and Kubernetes can help the research company develop and operate high-performance AI applications.

### Possible Services

- Vertex AI
- Compute Engine
- Google Kubernetes Engine
- Cloud Storage

## Client D – Global E-Commerce Company

### Recommended Platform

AWS

### Recommendation

I recommend AWS because the company requires highly available and scalable infrastructure for customers around the world. AWS provides global infrastructure and services that can distribute workloads and automatically increase or decrease capacity according to demand. These capabilities are useful for an e-commerce platform that may experience significant changes in traffic.

### Possible Services

- Amazon EC2
- Amazon S3
- Elastic Load Balancing
- EC2 Auto Scaling
- Amazon RDS

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services, scalability, and flexible infrastructure can support a growing startup. |
| Enterprise Organization | AWS / Azure | Both provide extensive enterprise services, security, scalability, and management capabilities. |
| Microsoft Environment | Azure | Strong integration with Microsoft technologies and enterprise identity systems. |
| AI / Machine Learning | GCP | Strong AI, machine learning, data analytics, and GPU-enabled infrastructure. |
| Kubernetes Deployment | GCP | Strong Kubernetes ecosystem through Google Kubernetes Engine (GKE). |
| Global Web Application | AWS | Broad global infrastructure and scalable services can support globally distributed applications. |
